# Site web de l'ACVES

Site du **Collège Algérien de Chirurgie Vasculaire et Endovasculaire** – en ligne sur https://acves.netlify.app

Chaque modification enregistrée ici est publiée automatiquement sur le site en environ une minute.

## Fichiers

| Fichier | Contenu |
|---|---|
| `index.html` | La page principale (textes, événements, actualités, formulaires) |
| `merci.html` | Page affichée après l'envoi d'un formulaire |
| `hero.jpg` | Image de couverture (ordinateur) |
| `hero-mobile.jpg` | Image de couverture (téléphone) |
| `logo-acves.png` | Logo |
| `flyer-save-the-date.jpg`, `flyer-programme.jpg` | Affiches du 2ème Congrès |

## Modifier un texte

1. Ouvrez `index.html`, puis cliquez sur l'icône crayon (✏️ « Edit this file »).
2. Utilisez **Ctrl + F** pour trouver le texte à changer, puis modifiez-le.
   Ne touchez pas aux balises entre `<` et `>`.
3. Cliquez sur **Commit changes…**, écrivez une courte description, puis **Commit changes**.
4. Le site est mis à jour en environ une minute (rafraîchir avec **Ctrl + F5**).

## Remplacer une image

1. Cliquez sur **Add file → Upload files**.
2. Déposez la nouvelle image **avec exactement le même nom** (par exemple `hero.jpg`).
3. Cliquez sur **Commit changes**.

## Annuler une erreur

Onglet **Commits** : chaque modification y est enregistrée. Ouvrez la modification à annuler et
restaurez l'ancienne version du fichier, ou demandez de l'aide à un autre administrateur.

## Inscriptions et abstracts

Les formulaires envoyés depuis le site (inscriptions, abstracts, contact) ne sont **pas** stockés ici.
Ils se trouvent dans le compte Netlify (Forms) et sont envoyés par e-mail à info.acves@gmail.com.
